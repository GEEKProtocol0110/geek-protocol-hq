# Official starting sources for institutional planning

Checked October 15, 2026. These sources inform planning, not Geek certification, eligibility, partnership or legal compliance. Recheck requirements for the actual learner group, buyer and solicitation.

| Source | Planning use |
| --- | --- |
| [SAM.gov registration](https://sam.gov/entity-registration) | Distinguishes full registration for prime federal awards from a UEI-only record. Neither establishes an award. |
| [SBA counseling](https://www.sba.gov/counseling/) and [government contracting office](https://www.sba.gov/about-sba/sba-locations/headquarters/office-of-government-contracting/) | Procurement-readiness/APEX assistance and prime/subcontract discovery. |
| [Michigan SIGMA](https://www.michigan.gov/budget/Budget-Offices/SIGMA) | Official state vendor entry point. No registration is performed here. |
| [Education Department student privacy](https://studentprivacy.ed.gov/) and [FERPA](https://studentprivacy.ed.gov/ferpa) | Student-record/vendor guidance to assess for a specific school use. |
| [FTC COPPA rule](https://www.ftc.gov/legal-library/browse/rules/childrens-online-privacy-protection-rule-coppa) and [FAQs](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions) | Children's privacy requirements to assess for the actual operator, ages, information and use. |
| [1EdTech LTI](https://www.1edtech.org/standards/lti), [OneRoster](https://www.1edtech.org/standards/oneroster), [specifications](https://www.1edtech.org/specifications) | Candidate tool/roster/assessment interchange; verify implementation and certification requirements before conformance claims. |
| [ADL xAPI specification](https://github.com/adlnet/xAPI-Spec) | Learning-activity communication reference; no military relationship or endorsement is implied. |
| [Section508.gov ACR guidance](https://www.section508.gov/sell/acr/) | An Accessibility Conformance Report explains evaluated product accessibility; naming it does not supply evidence. |

No third-party prose or standard is copied into the product. The [institutional path](INSTITUTIONAL-PATH.md) and [pilot charter](PILOT-CHARTER.md) are project proposals informed by these references and the founder's direction.
