# Hall of Thanks

First dedication: October 8, 2026. Public page: `/thanks/`.

The founder requested a lasting place in Geek history for Kaspa, the tools used to build the project and the Kaspa community behind it. The first edition credits the network and its contributors, the GEEKonKAS community collectively, verified HQ dependencies/services, founder-used AI development/creative tools and educational sources. It preserves the index-card origin already described on Home. No individual supporter names or handles were supplied for this edition.
