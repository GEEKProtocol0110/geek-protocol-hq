## How these documents become official

1. Review factual descriptions against the exact release and resolve discrepancies with newer maintained decisions. In particular, the disabled Mainnet schedule supersedes the older per-round planning example; it does not activate payments.
2. Approve or revise proposed standards, assign policy and review owners, and define effective dates. A documentation PR is not an independent security assessment or a legal review.
3. Run repository checks in a working execution environment; confirm generated continuity output and source links. Record exact-head CI and review results.
4. Prepare readable web and PDF editions from the accepted sources, with matching version, status and source identity. Inspect links, mobile layout, typography and print pagination before publication.
5. Publish approved editions through the Official Files area with versioned downloads and a change log. Retain old versions and mark superseded material. No new public /files/ route or PDF export is shipped by this source-only change.

## Document boundaries

The account guide is factual implementation guidance, not a complete privacy notice. The contributor charter and fair-play standard contain proposed process that requires adoption. The brand guide creates no new intellectual-property license. The roadmap creates no delivery date or institutional agreement.

CCE remains held at 1,000 distinct source-reviewed concepts in each of eight categories plus separate economy approval. Contributor rates are unselected. Treasury settlement and collection ownership remain disabled. Neither merging these drafts nor publishing a document can open those gates.
