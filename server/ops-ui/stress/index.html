Test the current credit rules and a hypothetical token budget. This tool calculates only: it changes no game rules, player balances, journals, reward queues or wallet funds.

Alpha credits and GEEK tokens are separate. No credit-to-token conversion is modeled. Reserve amounts are assumptions you enter, not verified funding. Burn pending is an allocation, not a confirmed burn.

Proposed round rewards and reserve runway

Launch proposal: 100 GEEK per qualifying completed round. This is not a per-answer or daily reward. Eligibility and per-player limits are not finalized. At the founder-provided reference of 100,000 GEEK per KAS, one 100-GEEK reward equals 0.001 KAS; this is not a live market quote.

The default daily cap of 100,000 GEEK is an editable scenario assumption, not a finalized launch limit. Daily forecasts hold activity and fees constant.

All listed fees arrive before equal-sized proposed rewards in the batch or on each modeled day. Fees below are the eligible platform fee portion, not the gross transaction amount. The 70/30 split is applied to each receipt. This example assigns all recycling to the modeled reward reserve; other pool allocations would reduce its budget.
