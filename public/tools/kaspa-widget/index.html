Set up on Android

  1. Download in your browser. Open this page in Chrome or Samsung Internet and tap Download Android APK.
  2. Open the finished file. In My Files → Downloads, tap the .apk. If Android asks, allow that browser or file manager to install this app. You can turn that permission off afterward.
  3. Install or update. Install over the existing signed app to keep settings and widgets. An older debug test build is a separate app. The public app is not on Google Play yet.
  4. Make it yours. Open Kaspa Live Widget, choose your currency, appearance and refresh interval, then tap Apply settings.
  5. Add the widget. Use Save & add, or hold an empty home-screen area → Widgets → Kaspa Live Widget. Hold the widget to resize it.

Hosted in Scriptable

Set up on iPhone

This version runs inside Scriptable. It is an early release awaiting a real iPhone trial; it is not a standalone App Store app.

  1. Install Scriptable. Get the free Scriptable app from the App Store ↗.
  2. Copy the widget below. In Scriptable, tap +, paste the entire script, and name it Geek Kaspa Widget. No file download is needed.
  3. Run it once. Tap the play button and choose Preview medium. BPS begins at “Sampling…”; it needs two successful samples at least 30 seconds apart.
  4. Add it to your Home Screen. Touch and hold an empty area → Edit → Add Widget (or +) → Scriptable. Choose medium and tap Add Widget.
  5. Select your script. Hold the new widget → Edit Widget → Script → Geek Kaspa Widget. Set When Interacting to Run Script, then close the panel.

Choose a color and widget size

Small, medium and large Home Screen widgets are supported. Medium is the best place to start. Lock Screen widgets are not supported.

In Edit Widget → Parameter, enter mint, cyan, violet or xray. For example, theme=violet;chart=off;refresh=15 chooses purple, hides the chart and requests a refresh after 15 minutes. Refresh choices are 15, 30 or 60; iOS can delay them.

In-app previews use the defaults at the top of the script. The Home Screen parameter applies to that widget.

Refresh, stale readings and missing data

Run the script and choose a preview to fetch again. A preview can update before the Home Screen does. iOS schedules Home Screen refreshes; continuous live updates are not guaranteed.

iPhone prices use USD. The backup USDT quote is labeled as an approximation. A delayed feed keeps its last good reading and timestamp; a missing chart does not draw an invented line. The medium and large header time shows when the widget rendered.

“Sampling…” is normal on the first run. Wait at least 30 seconds and run again. An outage, a counter reset or a gap longer than six hours can require another pair of samples.

Copying is blocked or the widget is blank

If your browser blocks automatic copying, the script appears in a text box. Use Select entire script, then Copy. You can also open View script as text in Safari and copy it there.

A blank widget usually needs its Script field set in Edit Widget. If Scriptable shows an error, confirm the entire script was pasted, including the final await run(); line. Note the exact error and line number when reporting a problem.

A little more help

Android opens the file but won’t install it

Use the APK, not the AAB Play upload bundle. Note the exact Android message. Keep the existing signed app installed; uninstalling can remove saved settings. An existing debug test app uses a separate package.

I installed Android but can’t find the widget

Open Kaspa Live Widget once, then hold an empty home-screen area and choose Widgets. Find Kaspa Live Widget and drag a size onto the home screen. Some launchers need a moment to refresh their widget list.

Does the widget need my wallet?

No. Both versions read public market and network data. They do not need your account, wallet address, seed phrase or private key. Saved settings and readings stay on your device. Scriptable has its own app settings and privacy policy.
