Set up in a few taps

  1. Download the APK. Use Chrome or Samsung Internet on your Android phone.
  2. Open Downloads. Tap the finished .apk file. If Android asks, allow that browser or file manager to install this app. You can turn that permission off afterward.
  3. Install or update. Keep your existing signed app installed. A debug test build is a separate app.
  4. Make it yours. Open Kaspa Live Widget, choose Appearance and your settings, then tap Apply settings.
  5. Add the widget. Use Save & add, or hold an empty home-screen area → Widgets → Kaspa Live Widget. Hold the widget to resize it.

Download or installation stuck?

It reaches 100% but never finishes

Open your phone’s My Files → Downloads and check for a completed APK. If there isn’t one, cancel the stalled download and open this page directly in Chrome or Samsung Internet. Download from here again, or use the GitHub link above. A full progress bar alone does not confirm the file is ready to install.

The file opens, but Android won’t install it

Check that you downloaded the APK, not the AAB Play upload bundle. Note the exact Android message. Keep the existing app installed; uninstalling can remove saved settings. An existing debug test app uses a separate package.

I installed it, but can’t find the widget

Open Kaspa Live Widget once, then hold an empty home-screen area and choose Widgets. Find Kaspa Live Widget and drag a size onto the home screen. Some launchers need a moment to refresh their widget list.

The readings look old

Tap the widget to refresh. Check the reading times and your connection. Battery settings can delay scheduled updates, and public providers can be temporarily unavailable. A cached value is not a live quote.
