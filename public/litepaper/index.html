01
THE PROBLEM

Learning creates value. Most platforms fail to recognize it.

Traditional trivia ends when the score appears. Traditional learning platforms measure completion, not verifiable performance. Geek Protocol connects knowledge, competition, community-authored content, reputation, and transparent accounting in one system.

It began with index cards for a father and son. The mission grew, but the core idea did not: make learning feel worth doing.
02
PROOF-OF-LEARNING

A result should be earned, reproducible, and auditable.

The current Alpha keeps ranked questions, correct answers, deadlines, scoring, and leaderboards on the server. The browser receives only one shuffled question at a time and cannot directly write a score.

Private answers

Correct choices never ship in the public game bundle.

Write-once attempts

Opaque tokens and atomic claims stop replayed or parallel answers.

Visible evidence

Sources and explanations appear after an answer is locked.

Honest accounting

Alpha credits remain visibly separate from real on-chain tokens.

03
THE GEEK GAUNTLET

Ten rounds. Rising risk. A reason to learn.

Players choose a knowledge category and face ten questions per round under a server clock. Round one is free. Later rounds spend Alpha GEEK from the practice ledger. After each completed round, the player can continue or close the run.

  • Eight selectable knowledge categories
  • Cryptographically shuffled questions and answer order
  • Speed and streak scoring computed by the server
  • Category-specific verified leaderboards
  • Source-linked review after every locked answer
04
COMMUNITY CONTENT ENGINE

The community expands the game without weakening the truth.

Contributors submit an original question, four answers, an explanation, and a primary source. The submission stays private until a human moderator reviews and publishes it. A published question can earn one Alpha ledger credit when it is first used in ranked play.

SUBMIT→REVIEW→PUBLISH→FIRST USE→CREDIT

Credits are not currently transferable, withdrawable, or guaranteed to become tokens.

05
THE VALUE LAYER

Wallet-neutral rewards, gated settlement.

Geek Protocol is being designed so an eligible participant can choose any valid Kaspa mainnet receiving address. Kasware may provide a convenient connection, but it is not intended to control where rewards are sent.

06
TRUST MINIMIZATION

No seed phrases. No hidden payout switch.

  • Geek Protocol must never request or store a player’s seed phrase or private key.
  • Wallet connection and signing happen only after an explicit player action.
  • Identity uses short-lived, single-use server challenges, public-key/address matching, and server-side signature verification.
  • Protected payout changes require fresh wallet proof; every destination starts a 72-hour future-settlement cooldown.
  • Sensitive Alpha changes create pseudonymous integrity-protected audit evidence.
  • Production requires both an independent Web3 application penetration test and a separate audit of value-moving settlement code.
