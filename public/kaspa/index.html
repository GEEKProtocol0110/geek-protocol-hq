02 / MAINNET MILESTONES

FROM LAUNCH
TO TOCCATA.

Kaspa's performance and programmability arrived in staged protocol upgrades. Future research is clearly separated from active mainnet capability.

  1. 2021
    MAINNET

    Fair-launched proof-of-work blockDAG.

    Kaspa launched publicly in November with no premine or presale.

  2. 2025
    CRESCENDO · MAY 05

    One block per second became ten.

    The hardfork activated KIP-9, KIP-10, KIP-13, and KIP-15 and raised the target rate to 10 BPS.

  3. 2026
    TOCCATA · JUN 30

    UTXO-native programmability.

    Transaction v1, covenants, script pricing, user lanes, Based Apps, and Inline ZK foundations activated at DAA score 474,165,565.

  4. NEXT
    RESEARCH / DEVELOPMENT

    DAGKnight is not mainnet yet.

    DAGKnight proposes responsiveness to actual network conditions. It has no fixed activation date and should not be described as live.

03 / BUILDER SURFACE

STATE,
THE UTXO WAY.

Toccata expands what can be expressed directly through transactions while keeping Kaspa's UTXO model. Production builders should start from official documentation and current tooling.

01

Covenants

Transaction rules can constrain how outputs are spent, enabling verifiable state transitions without an account-style global state machine.

02

Based Apps

Applications can coordinate state through chained UTXOs and network-native verification patterns.

03

Inline ZK

Zero-knowledge verification primitives create a path toward privacy and compact proofs inside transaction logic.
