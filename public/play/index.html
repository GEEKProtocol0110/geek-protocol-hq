      GAUNTLET RULES

      Climb or end the run.

      1. Round 1 is free. Later rounds charge server-tracked Alpha GEEK when you enter.
      2. Answer ten questions. The server chooses each question, withholds the answer, and enforces the 15-second deadline.
      3. Build a streak. Consecutive correct answers add a growing score bonus.
      4. Earn by accuracy. Correct answers earn the round’s displayed reward.
      5. Choose after every round. Continue and risk another entry fee, or end the run.
      6. Trust the board. The browser cannot write scores; only completed server-scored rounds can rank.
      7. Review the source. Every Kaspa answer reveals its cited primary source only after it is locked.
      8. Use quick modes safely. Daily Signal allows one five-question attempt per UTC day. Speed Signal uses one 30-second server clock. Both award XP and verified scores, not Alpha GEEK.
